## About the Project

The **AI Academic Assistant** is a personal productivity and research tool designed to:
- Answer academic questions using AI
- Help organize research and study notes
- Assist with assignments, proposals, and reports
- Store all important findings in one place

This repository is the **single source of truth** for all work, research, instructions, and code related to this project.

## Folder Structure

```
AI-academic-assistant-2/
│
├── README.md                  ← You are here. Project overview & guide.
│
├── frontend/                  ← All web UI files (HTML, CSS, JavaScript)
│   └── index.html             ← Main web app interface
│
├── backend/                   ← Server-side code (Python, APIs)
│   └── app.py                 ← Main backend application
│
├── docs/                      ← All documentation
│   ├── architecture.md        ← System design and architecture overview
│   ├── research/              ← Research papers, summaries, findings
│   └── instructions/          ← Step-by-step guides and how-tos
│
├── assets/                    ← Images, diagrams, design files
│
└── notes/                     ← General notes, ideas, important information
    ├── important-info.md      ← Key facts and critical information
    └── progress-log.md        ← Daily log of work done
```

## Getting Started

### Prerequisites
- Python 3.8 or higher
- A modern web browser
- Git

### Running the Frontend
1. Open `frontend/index.html` in your browser — no server needed.

### Running the Backend
```bash
cd backend
pip install -r requirements.txt   # (when dependencies are added)
python app.py
```

## How to Contribute / Save Work

Every time new work is done:
1. Save files in the correct folder (see structure above)
2. Update `notes/progress-log.md` with what was done
3. Run:
   ```bash
   git add .
   git commit -m "Short description of what was done"
   git push
   ```
